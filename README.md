# 🥗 Nutrition Label (Typography Project)

A responsive, pixel-perfect digital **Nutrition Facts Label** built using semantic HTML5 and custom CSS3. This project focuses on modern web typography standards, complex element alignment, flexbox layout techniques, and strict accessibility structure.

Developed as part of the **freeCodeCamp Responsive Web Design Certification**.

---

## 🚀 Live Demo

- **GitHub Repository:** [https://github.com/Regalson001/nutrition-label](https://github.com/Regalson001/nutrition-label)

---

## 📌 Features

- **Semantic Markup:** Built with clean HTML5 container hierarchy (`<header>`, `<div>`, `<p>`, `<span>`, `<h1>`–`<h2>`).
- **Flexbox Layouts:** Uses CSS Flexbox (`justify-content: space-between`, `align-items: flex-end`) for fluid text alignment.
- **Custom Typography:** Styled using Google Fonts (`Open Sans`) with precise font weights (`400`, `700`, `800`) and custom rem/em sizing.
- **Micro-Formatting:** Features nested indentations (`.indent`, `.double-indent`), varied border dividers (`.large`, `.medium`, `.divider`), and custom line spacing.
- **Responsive Design:** Fits standardized real-world label dimensions (`270px` width) with scalable box-sizing rules.

---

## 🛠️ Built With

* **HTML5** – Structure and semantic layout
* **CSS3** – Custom styling, Flexbox, and typography rules
* **Google Fonts** – Open Sans (`400`, `700`, `800`)
